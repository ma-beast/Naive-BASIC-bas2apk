NaiveWORK BAS-APK-MAKER 0.8G

Добавлена генерация уникального Android package ID из имени .BAS.

Примеры:
TANK.BAS -> приложение TANK, package com.naivework.tank
Моя-игра.BAS -> приложение Моя-игра, package com.naivework.moya0igra

Кириллица транслитерируется простой схемой. Для package ID недопустимые символы заменяются на 0.
Дефис '-' в Android package ID использовать нельзя, поэтому он также заменяется на 0.
Если имя начинается не с латинской буквы, перед идентификатором добавляется 'p', поскольку сегмент
package ID должен начинаться с буквы.

Сборка, файловый браузер, замена BAS, изменение label и старая V1-подпись сохранены.
