# Naive BASIC bas2apk 1.0

Утилита превращает программу `.bas` в автономный Android APK.

Рабочая схема 1.0:

1. Файловый браузер стартует с `Environment.getExternalStorageDirectory()`.
2. Выбирается файл `.bas`.
3. В качестве шаблона используется **NaiveWORK 0.2G** (`app/src/main/assets/NaiveWORK_0.2G.apk`).
4. `assets/programs/program.bas` в шаблоне заменяется выбранной BASIC-программой.
5. Имя установленного приложения берётся из имени `.bas`.
6. Для каждой программы формируется отдельный package id `com.naivework.<имя>`.
7. Готовый APK подписывается встроенным ключом NaiveWORK Export в исторической V1/JAR-схеме, совместимой со старыми Android.
8. APK сохраняется рядом с исходным `.bas` под тем же базовым именем.

## Важное изменение 1.0

NaiveWORK 0.2G собран на интерпретаторе NaiveBASIC 0.9.3G-BETA. Новый шаблон использует `android:label` через ресурс, а не литеральную строку внутри бинарного AndroidManifest.xml. Старый bas2apk искал буквальную строку `Naive WORK` и поэтому не умел корректно подготовить новый шаблон.

В 1.0 `BinaryXmlLabel` умеет менять `android:label` как при старой литеральной записи, так и при ресурсной ссылке нового NaiveWORK: в string pool добавляется имя программы, а атрибут `<application android:label>` переключается на эту строку. Package id меняется отдельно, как раньше.

Встроенные `export_private.pk8` и `export_cert.der` проверены: RSA-ключ и сертификат составляют одну пару.

Название программы: **Naive BASIC bas2apk**. Версия: **1.0**.
